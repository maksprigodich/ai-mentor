# AI-Mentor 2.0

Полноценный MVP AI-наставника: серверная авторизация, профиль пользователя, постоянные чаты, история и подключение настоящей AI-модели через OpenAI-compatible Chat Completions API.

## Запуск

1. Установить Node.js 18+.
2. В папке проекта выполнить `npm install`.
3. Скопировать `.env.example` в `.env`.
4. Обязательно заменить `JWT_SECRET` на случайную строку.
5. Для настоящих ответов AI заполнить `AI_API_KEY` и при необходимости `AI_API_URL` / `AI_MODEL`.
6. Запустить `npm start`.
7. Открыть `http://localhost:3000`.

Без `AI_API_KEY` интерфейс и сервер всё равно запускаются, но чат покажет сообщение о необходимости настройки AI-провайдера — это специально, чтобы не выдавать заглушку за настоящий ИИ.

## Архитектура

- Express — HTTP/API и раздача фронтенда.
- SQLite — пользователи, хешированные пароли, профили, чаты, сообщения, база вузов.
- JWT — сессия клиента.
- bcryptjs — хеширование паролей.
- AI API — серверный вызов модели; ключ никогда не попадает во frontend.

## Следующий уровень
